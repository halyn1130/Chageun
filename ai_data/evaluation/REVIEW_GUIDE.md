# 평가 기준

현재 24문항은 질문 초안이며 정답이 검증된 평가셋이 아닙니다. 18문항은 법규/차량 RAG, 6문항은 개인 기록·지도·대화·범위 밖 동작 확인용입니다.

## 검토 절차

1. 차량 질문은 등록 설명서와 연식·파워트레인 일치 확인.
2. 원문 PDF에서 답의 근거를 찾고 PDF 페이지와 인쇄 페이지 구분.
3. chunks.jsonl에서 대응하는 청크 ID를 `expected_chunk_ids`에 기록.
4. 조건·예외·단위가 포함된 기대 답변을 `reference_answer`에 작성.
5. 검토자 `reviewer`와 `status=reviewed` 기록. 인덱스 변경 시 ID를 다시 확인.
6. 검색 CLI와 답변 CLI 결과를 별도로 확인.

## 답변 수동 평가 (각 0 / 1 / 2)

- 근거 일치: 문서 내용과 답변의 사실이 일치하는가?
- 조건 보존: 연식·동력계통·일반/가혹조건·법규 예외가 보존되는가?
- 출처 정확성: 인용한 청크/페이지가 실제 답변을 뒷받침하는가?
- 음성 전달: 짧은 음성 답변에서도 중요한 조건·주의가 빠지지 않는가?
- 정보 부족 대응: 모르는 내용은 추가 질문 또는 근거 부족으로 처리하는가?

점수는 미실행이면 빈칸으로 둡니다. 출처가 존재한다는 이유만으로 근거 일치에 만점을 주지 않습니다.

## 실패 원인 기록

| 구분 | 확인할 항목 | 주 담당 |
|---|---|---|
| 수집 | 필요한 문서가 없거나 버전이 다름 | 현준·하린 |
| 추출 | 표/단위/경고가 깨짐 | 현준 |
| 청킹 | 조건과 본문이 분리됨 | 현준·준영 |
| 필터 | 차종/연식/파워트레인 값 불일치 | 현준·준영·하린 |
| 검색 | 맞는 청크는 있지만 순위 밖 | 준영 |
| 답변 | 맞는 근거에도 과장/누락/잘못된 인용 | 준영 |
| 범위 | 지도/개인기록 질문을 문서만으로 답함 | 준영·하린 |

평가 보고서에는 사용 인덱스 버전·문서 개정판·모델·평가 날짜를 함께 기록합니다.
