# 차근 Vue 프론트엔드

## 로컬 실행

프로젝트 루트의 Docker 서비스(`db`, `auth-server`, `api-server`, `rag`)를 먼저 실행합니다.

```bash
docker compose up -d --build
cd frontend
npm install
npm run dev
```

브라우저: <http://localhost:5173/>

`/api/*`는 FastAPI 8002, `/auth/*`는 Java 인증 서버 8080으로 Vite가 프록시합니다.

## 상태

- **PC / 모바일 시연 전환**: 상단 버튼으로 1280×480 와이드와 390×844 모바일 화면을 전환합니다. 같은 iframe의 크기만 바꿔 입력·대화·선택 차량을 유지합니다. 모바일은 중앙의 큰 마이크와 하단의 주제 카드 세 개로 구성하며, 실제 좁은 화면에서는 모바일 모드를 기본으로 엽니다. 12.3형은 시연 기준이며 실제 K5 패널 해상도를 검증한 값은 아닙니다.
- **모바일은 대화로 진행**: 대화를 시작하면 중앙 마이크와 선택형 카드를 없애고 대화 내용·하단 입력창·작은 마이크만 남깁니다. 색·모양·차량 확인은 음성과 같은 문장으로 안내하며 말이나 글로 답합니다. 메뉴에서 상담을 시작해도 같은 대화 화면으로 연결됩니다. 정비 기록 조회는 서버에서 받은 기록의 날짜와 주행거리를 문장으로 전달합니다.
- **상태에 반응하는 원형 모션**: 듣는 중·답변 준비 중·읽는 중에 빛과 형태가 흐르는 원을 표시합니다. 모바일 대화에서는 입력창 위에 작게 표시하고, 홈에서는 큰 마이크 둘레에 표시합니다. 움직임 줄이기 설정을 따릅니다. 실제 음량 분석을 추가한 모션은 아닙니다.
- **모바일 내 차 케어**: 차량 요약부터 소모품까지 한 페이지로 스크롤합니다. 관리/기록 탭은 스크롤 중에도 보이며 상세에서 목록으로 돌아오면 위치를 복원합니다. 차량 선택·정비 기록 입력은 하단 패널로 열립니다.
- **음성 대화가 기본**: 큰 마이크 버튼 → 듣기 → 확인 → 답변 읽기 → 다음 질문. 글 입력은 보조 버튼으로 엽니다. 하단 목적지는 **홈 / 내 차 케어** 두 개입니다. 홈은 마이크와 경고·이상 / 기능·조작 / 도로 규칙을 모은 시작 화면입니다. 정비 이력은 내 차 케어 안에서 조회하며 별도 중복 화면을 두지 않습니다.
- **브라우저 음성 인식**: SpeechRecognition(또는 webkitSpeechRecognition)과 speechSynthesis를 사용합니다. 클릭해야 마이크를 시작하며, 화면 이동·대화 종료·탭 숨김·모달 열기 때 인식과 재생을 중지합니다. Chrome 등 지원 브라우저, 마이크 권한, 네트워크가 필요합니다. 브라우저 제공자의 인식 서비스로 음성이 전송될 수 있습니다. develop의 `voice-ai` 서비스에는 실제 Whisper STT/OpenAI TTS가 추가됐지만 현재 웹 화면은 이 별도 서비스를 호출하지 않습니다.
- **화면 없이 답할 수 있는 음성 질문**: 화면에는 짧은 질문과 선택지를 표시하고 `spokenReply.js`가 같은 선택지를 완결된 음성 안내로 만듭니다. 경고등 색·모양·좌석과 `모르겠어요` 응답을 읽어주며, 동일한 질문·답변은 중복 재생하지 않습니다. 안내 음성이 끝난 뒤 듣기를 재개합니다. RAG의 `answer`는 짧은 화면 문장, `speech_text`는 적용 조건과 조작 순서를 포함한 친절한 음성 문장으로 생성합니다.
- **부품 시각화**: 생성한 차체와 부품 강조 이미지를 같은 좌표에 정렬했습니다. 차체 불투명도는 0.5이고 SVG clipPath로 선택한 부품만 선명하게 겹칩니다. 엔진·오일 계통·브레이크·12V 배터리·타이어·연료 탱크·냉각 계통·실내 안전장치·와이퍼 9종에 빨강·주황·청록 각각의 재생성 PNG, 총 27장을 사용합니다. 부품에 색상 필터를 씌우지 않고 실제 생성 이미지의 금속 질감과 음영을 유지합니다. 기준 없는 항목은 중립 이미지로 표시합니다. 표시된 부위는 계통 위치의 개념도이며 실제 K5 부품 배치나 고장 확정 결과가 아닙니다.
- **범주마다 다른 탐색**: 대화 홈은 **경고·이상 / 기능·조작 / 도로 규칙** 세 개의 넓은 카드입니다. 각 카드에 도움 범위와 하위 주제를 표시하며, 정비 카드와 중복 정비 제안은 제거했습니다. 내 차 케어는 10개 소모품을 개별 사용량 카드로 표시하고, 교환 기준에 가까운 순서로 정렬해 세로로 스크롤합니다. 경고는 6가지 증상 → 필요한 설명, 조작은 자동차 그림을 빼고 온도·공기 / 시야·조명 / 시트·편의 / 주행 보조 네 묶음에서 11개 기능을 바로 선택하며, 도로 규칙은 4개 상황 그룹/9개 주제로 나눴습니다. 홈과 관리 화면에서 같은 메뉴를 반복하지 않습니다.
- **공통 로고**: 루트 `image.png`에서 내장 image_gen으로 흰 배경과 내부 여백을 투명하게 추출했습니다. 앱 헤더·시연 프레임·인증 모달·서버 로그인/가입·파비콘에서 동일한 로고를 사용합니다. 어두운/밝은 테마는 같은 알파 형상의 명도를 맞춥니다.
- **정비 10종**: 엔진오일·오일필터·엔진 에어필터 / 타이어·브레이크 패드·브레이크액 / 에어컨 필터·와이퍼 / 배터리·냉각수. `guidance.js`의 동일한 식별자를 탐색, 기록 폼, RAG 문맥에서 사용합니다. 필터 종류를 서로 다른 기록으로 구분합니다.
- **차량 모션**: 최초 관리 화면에서 이미지 디코딩 후 0.95초 동안 하나의 빛 마스크가 앞에서 뒤로 훑습니다. 차체의 흰빛과 부품 강조를 같은 레이어에 합성해, 빛이 닿은 부품이 동시에 밝아졌다 짧은 잔광과 함께 사라집니다. 부품별 지연 타이머는 없으며 실제 위치가 점등 순서를 결정합니다. 실제 차량을 검사하는 기능이 아닌 부품 탐색 안내입니다. 에어컨 필터 선택은 사용자가 요청한 기존 앞쪽 강조 이미지로 복원했으며, 실제 필터 위치도는 아닙니다. 항목 선택은 모션을 중지하고 선택 부품을 표시하며 `prefers-reduced-motion`에서는 소개 모션을 생략합니다.
- **기록으로 보는 사용량**: 10개 소모품 각각에 부품 아이콘, 원형 게이지, 사용 거리/관리 기준, 경과 기간/관리 기준을 표시합니다. 거리·기간 중 더 많이 사용한 비율로 내림차순 정렬합니다. 90% 이상 빨강(교환 임박/시점), 70~89% 주황(교환 준비), 70% 미만 청록(여유)입니다. 100%를 넘는 사용량도 실제 숫자는 유지하고 그래픽만 제한합니다. 기록 없음·조회 실패는 회색이며 0%로 꾸미지 않습니다.
- **짧은 질문의 문맥**: 부품 화면에서 “언제 갈아?”라고 입력하거나 말하면 선택 항목을 보존합니다. 명확하게 다른 질문을 하면 새 주제로 이동합니다. 선택지 응답은 현재 질문의 답으로 유지합니다.
- **경고등 8종**: 엔진, 오일 압력, 충전, 브레이크, 공기압, 연료, ABS, 에어백. 기아 K5 2024 공식 설명서의 의미와 행동 안내를 수동으로 정리했습니다. 색·모양의 설명이 충돌하거나 모호하면 프론트가 경고를 확정하지 않습니다.
- **엔진오일 교환 시기**: K5 2024 가솔린 1.6T에만 적용. 통상 10,000 km/12개월, 가혹 5,000 km/6개월 중 먼저 도래하는 시점입니다. 마지막 기록 이후 교환 여부와 운행 습관을 먼저 확인합니다. 사용자가 기록 이후 교환했거나 운행 조건을 모르면 단일 교환 시기를 확정하지 않습니다. 확인된 최근 기록 날짜와 거리로 계산하고, 자료가 없는 다른 차종에는 계산값을 표시하지 않습니다.
- **관리 화면 구분**: 왼쪽은 진한 주행거리와 교환 임박 항목만 표시하고, 차 아래에는 은은한 받침을 둡니다. 상단의 소모품 관리/정비 기록은 별도 남색 바탕과 밝은 선택 탭으로 분리합니다. MY CAR, 영어 장식 문구, 교환이 가까운 순/시연 기준 목록 제목은 제거했습니다.
- **정비 기록**: `소모품 관리 / 정비 기록` 탭으로 현재 사용량과 과거 기록을 분리합니다. 기록은 날짜순 목록과 항목 필터로 조회하고, 상단 `기록 추가`에서 입력합니다. 기록에서 부품을 열었다 돌아오면 필터를 유지합니다. JWT 로그인과 사용자 소유 차량 CRUD, 기록 조회·추가·필터는 최신 develop의 MariaDB API에 연결했습니다. 새로고침 후에도 저장되며 계정 전환 시 이전 차량·기록·대화 캐시를 비웁니다.
- **공업소 찾기 제거**: 사용자 범위 변경에 따라 관리 홈·상세·상담 결과의 모든 진입점과 검색 화면, 지도 SDK, 위치 권한 요청을 제거했습니다. 장소 검색 질문은 지원하지 않는 기능으로 안내합니다. develop에 포함된 일반 장소 API는 화면에서 호출하지 않습니다.
- **시연 관리 기준**: 사용자가 요청한 모든 게이지 시연을 위해 오일필터·에어필터·타이어·브레이크 패드·브레이크액·에어컨 필터·와이퍼·배터리·냉각수에 별도 예시 기준을 정의했습니다. `[차근 시연]` 기록이 있는 차량의 관리 화면에서만 사용하며 제조사 확정 교환 주기나 실제 마모도로 제시하지 않습니다. 상세에 시연 기준을 표시하고 RAG 요청에는 이 예시 주기를 전달하지 않습니다. K5 2024 1.6T 엔진오일은 기존 검토 기준을 유지합니다.
- **홈과 대화의 구분**: 일반 대화의 `새 대화`와 답변마다 붙던 `질문으로 돌아가기`를 제거했습니다. 답변 뒤에는 빈 입력창과 `이어서 말하기`가 남으며, `홈`을 누르거나 음성으로 `홈으로 가줘`라고 하면 이번 상담을 마치고 시작 화면으로 돌아갑니다. 입력·확인 질문·대화 ID·마이크를 정리하고 늦은 응답은 무시합니다. 단계별 안내의 명확한 결론 화면은 기존 질문 수정 동작을 유지합니다.
- **RAG 요청 경로**: 경고등·엔진오일도 고정 안내로 빠지지 않고 `/rag-query`를 먼저 호출합니다. 차량 스냅샷, 항목별 최신 정비 기록, 추가 확인 답변을 `context`로 전송합니다. 실제 서버 답변을 우선하고 명시적인 `c_mock` 등 예시 응답에만 검토된 로컬 안내를 사용합니다. 서버의 `need_clarification`을 화면의 추가 질문 상태로 변환하고, `need_details`와 함께 원래 질문과 대화 ID를 유지합니다. 차량·정비 데이터는 API 서버가 소유권 확인 후 DB에서 조회한 값이 기준입니다.
- **자료 범위**: 위 K5 경고등·냉각수·오일 기준만 검토된 로컬 자료입니다. 실제 RAG는 `v9-law-paragraphs`의 2026 K5 G2.0·아반떼 G1.6 설명서와 법규를 검색합니다. 로컬 2024 기준을 2026 설명서로 대체하지 않으며, 2024 차량의 실제 RAG 설명서는 없으므로 근거 부재를 그대로 표시합니다. 가상 출처와 잘못된 목업 답변은 걸러냅니다. 현장 진행 여부나 잔여 주행 가능 거리를 확정하지 않습니다.

음성 인식의 브라우저 지원과 외부 서비스 처리 특성: [MDN SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition).

추가 API 계약은 [연결 메모](../docs/frontend-api-gaps.md), 생성 이미지 경로와 전체 프롬프트는 [이미지 제작 기록](public/images/README.md)에 정리했습니다.

## 파일 구성

- `src/DisplayPreview.vue`: PC / 모바일 전환, 크기 맞춤, 시연 초기화. `/?surface=1`은 반응형 앱을 직접 열 때도 사용합니다.
- `src/mobile.css`: 700px 이하에서 홈·대화·케어·하단 패널을 다시 배치하는 모바일 스타일.
- `src/components/VoiceOrb.vue`: 대화 상태별 원형 애니메이션과 움직임 줄이기 대응.
- `src/App.vue`, `src/style.css`, `src/cockpit.css`: 대화와 내 차 케어, 공통 모달·시연 프레임.
- `src/components/DiagnosticView.vue`: 항목 탐색·상세·정비 이력·확인 질문을 관리하는 화면. `GuidanceMenu.vue`는 홈 진입점만 담당합니다.
- `src/components/RoadContext.vue`, `GuideIcon.vue`: 도로 상황 개념도와 공통 기능 아이콘.
- `src/components/BrandLogo.vue`: 투명 로고 공통 컴포넌트.
- `artwork-prompts.json`: 재생성한 상태 이미지와 로고의 원본 경로·프롬프트·최종 경로.
- `src/components/VehicleStructure.vue`: 차체/부품 레이어. 기본 화면은 중립 상태이며 대화에 따라 강조합니다.
- `src/components/MaintenanceCard.vue`, `MaintenanceUsage.vue`, `src/maintenanceUsage.js`: 소모품별 목록/상세 게이지, 예시 관리 기준, 거리·기간 사용량과 우선순위 계산.
- `src/guidance.js`: 범주와 주제, 차량별 기록에 따른 규칙 기반 제안.

## 확인·빌드

2026-10-23 후속 요청으로 기본 차량 **붕붕이(id 2)**를 **K5 2026 G2.0**으로 변경했습니다. 현재 주행거리 36,200 km와 정비 기록 23건, 기본 차량 설정은 유지합니다. 붕붕이도 최신 설명서 RAG를 사용합니다. 아래 2024 엔진오일 계산 설명은 비교 차량에만 해당하며, 붕붕이의 엔진오일 게이지는 2026 기준이 아직 등록되지 않아 `기준 확인`으로 표시됩니다. 다른 9종의 명시된 시연 관리 기준은 유지합니다.

시연 계정은 아이디 `1`, 비밀번호 `1`입니다. 시연 데이터 정의는 차량 6대와 정비 기록 41건입니다. 실제 DB에 추가된 냉각수 기록 1건도 유지했습니다. 기본 차량 `붕붕이`에는 정비 10종과 기타 기록을 포함한 22건이 있으며 엔진오일은 최근 기록 이후 9,200 km/9개월입니다. 기존 2024 시연 구성은 와이퍼 기간 도래, 브레이크 패드 94%, 엔진오일·오일필터 92%, 배터리·에어컨 필터 교환 준비와 나머지 여유 상태를 함께 보여 줍니다. 차량 선택에서 `시연 · 거리 초과`, `시연 · 기간 초과`, `시연 · 기록 없음`, `시연 · 아반떼 비교`로 다른 상태를 확인할 수 있습니다. `시연 · K5 2026`(1,200 km, 기록 없음)은 새 설명서 RAG 시연용이며 기본 차량은 붕붕이 그대로입니다. 아반떼에 K5 교환 기준을 적용하지 않습니다. 데이터 정의는 [시연 데이터](../infra/db/demo-account-1.json)에 있습니다.

`src/conversation.js`는 대표 표현에 대한 **프론트 시연용 대화 상태**입니다. 원래 질문과 확인한 정보, 차량·정비 문맥을 `/rag-query`에 보내며, 질문 주제 변경·정보 모름·목업 오답 방어를 테스트합니다. 실제 질문 분류·설명서 검색은 연결된 RAG 서버가 맡습니다. 서버가 전달한 최근 3턴은 생략된 질문의 대상 해석에 사용합니다. 과거 답변은 근거로 인용하지 않고 이번 검색 문서에서 다시 검증합니다. 기록 기반 교환 시기 계산은 별도 확장이 필요합니다. 음성 세션의 중지·늦은 콜백·권한 거부와 정비 날짜·거리 계산도 테스트합니다. 자동 검증에서 실제 마이크는 켜지 않습니다.

정적 배포에는 `/api`와 `/auth`의 역방향 프록시 및 HTTPS가 필요합니다.
