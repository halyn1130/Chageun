# 프론트 연동과 검토 지점

## 화면과 대화 흐름

홈은 중앙 마이크와 경고·이상 / 기능·조작 / 도로 규칙의 시작 화면입니다. 하단 이동은 **홈 / 내 차 케어**로 나눴습니다. 일반 답변 뒤에는 대화를 이어갈 수 있고, 홈으로 이동할 때 이번 상담을 마칩니다. 대화 보관함이나 장기 기억은 추가하지 않았습니다.

| 화면 | 동작 |
| --- | --- |
| PC / 모바일 시연 | 1280×480 / 390×844 전환. 같은 iframe의 크기만 변경해 로그인·선택 차량·대화·작성 중인 글을 유지 |
| 모바일 홈 | 큰 중앙 마이크와 아래의 주제 카드 3개 |

| 내 차 케어 | 주행거리·교환 임박 항목, 소모품 10종의 개별 게이지, 날짜순 정비 기록·항목 필터·기록 추가 |
| 모바일 케어 | 한 페이지 세로 스크롤, 고정 관리/기록 탭, 상세에서 목록 위치 복원, 차량 선택·기록 추가 하단 패널 |
| 모션·이미지 | 듣기·생각·말하기 상태별 원형 모션, 차체·부품을 함께 훑는 0.95초 소개 모션, 부품별 빨강·주황·청록 이미지 |

조작 안내는 온도·공기 / 시야·조명 / 시트·편의 / 주행 보조로 구성합니다. 공업소 검색 화면과 지도 SDK·위치 권한 요청은 없습니다. 장소 검색 API는 기존 develop 구현을 유지하며 이번 프론트에서 호출하지 않습니다. 로고는 앱·시연 프레임·로그인/가입 화면에 공통 적용합니다.

## 다른 팀 코드에 미치는 영향

| 파일 | 변경과 검토 지점 |
| --- | --- |
| `backend/api-server/app/routers/rag.py` | 선택적 `context` 요청 모델 추가. UI에서 명시적으로 차량을 해제한 요청은 기본 차량으로 대체하지 않음. 기존 context 없는 호출은 호환 |
| `backend/api-server/app/routers/vehicles.py` | 설명서 카탈로그를 K5 2026 G2.0 / 더 뉴 아반떼 2026 G1.6에 맞춤. 개인 설정용 현재 주행거리 수정 API 추가. 정비 기록의 교환 시점 주행거리가 현재 차량 주행거리를 덮어쓰지 않도록 분리 |
| `ai_data/chageun_ai/agent.py` | 같은 상담의 최근 대화로 생략된 대상을 복원해 검색. 모호한 대상·증상은 내부 `ask_missing_detail`로 확인. 오일필터·에어컨 필터·브레이크액 기록 동작과 `엉따` 동의어 추가 |
| `ai_data/chageun_ai/core.py` | 선택 인자 `history=None` 추가. 짧은 화면 답변과 화면 없이 이해할 수 있는 음성 답변의 생성 지침 보완 |
| `backend/auth-server` | 로그인·가입 한글 문구와 공통 로고. Java 정적 파일 응답에 PNG MIME 타입 추가. 인증 로직은 동일 |
| `infra/db/migrations/20261023_conversation_messages.sql` | 기존 DB에 develop의 대화 테이블만 추가하는 멱등 마이그레이션. 회원·차량·정비 기록 보존 |

현재 주행거리 저장용 `PATCH /vehicles/{vehicle_id}/mileage`를 추가했습니다. 추가 외부 API 키나 DB 마이그레이션은 필요하지 않습니다. `context`는 선택 필드이며, 차량·정비 기록은 API 서버가 JWT 사용자 소유권을 확인한 DB 값이 기준입니다. 프론트가 보낸 차량 스냅샷이나 시연 게이지 기준을 공식 정비 근거로 사용하지 않습니다.

최신 develop의 검색 용어 보강, 선택 차량 힌트, 답변·음성의 근거 검증 및 재시도 동작을 유지하면서 연속 질문 처리를 합쳤습니다. 검색 인덱스나 검색 순위 알고리즘은 이 PR에서 변경하지 않습니다. 외부 검색으로 답변을 보완하는 기능은 이번 구현에 포함하지 않습니다.

## API 요청·응답과 세션

개인 설정의 `PATCH /vehicles/{vehicle_id}/mileage`는 `{ "mileage_km": 42000 }`을 받아 저장된 차량 정보를 반환합니다. JWT 사용자 소유 차량만 수정하며, 주행거리는 DB 범위 내 0 이상의 정수만 허용합니다. 과거 정비 기록은 변경하지 않습니다. 반대로 정비 기록 추가의 `mileage_km`은 **교환 시점 주행거리**로, 현재 주행거리를 기본값으로 제안하지만 사용자가 수정할 수 있습니다. 기록 추가 시 차량 주행거리를 자동으로 올리던 동작은 제거했습니다.

프론트는 기존 `/rag-query`의 `question`, `vehicle_id`, `conversation_id`와 선택적 `context`를 사용합니다. 원래 질문과 확인한 답을 `question`에 포함하고, `context`에는 진입 화면·항목·원문·확인 답·조회 상태를 담습니다.

- 실제 답변과 출처를 우선하며 `not_found`나 네트워크 오류를 로컬 정답으로 덮지 않습니다. 명시적인 목업 응답에만 검토된 로컬 안내를 사용합니다.
- `need_clarification` / `need_details`는 원문과 대화 ID를 유지한 추가 질문으로 연결합니다. 일반 확인은 `missing_fields: ["question"]`, 경고등 확인은 `["warning_light"]`로 구분합니다.
- 등록 차량의 별명 또는 차종·연식이 한 대를 식별할 때 말로 차량을 선택합니다. 여러 대가 일치하거나 부정 표현이면 임의 선택하지 않습니다.
- `open_my_car` 정비 이력 동작은 PC의 이력 열기와 연결됩니다. 모바일·음성에서는 이미 조회한 해당 차량의 최신 교환 날짜·주행거리를 문장으로 전달합니다. 조회 실패와 기록 없음은 구분합니다.

`history`는 기존 API 서버가 조회하는 같은 상담의 최근 대화입니다. AI에는 최근 6개 메시지, 각 2,000자 이하로 전달하며 질문의 생략된 대상을 이해하는 데만 씁니다. 답변의 근거와 인용은 이번 검색 문서에서 다시 검증합니다. 현재 질문의 정정·새 주제와 현재 선택 차량이 과거 대화보다 우선합니다. 후속 질문은 복원된 검색어로 검색하고 원문과 대화는 답변 검증 문맥으로 유지합니다. 기존 호출 횟수는 유지하지만 이력 전달에 따른 입력 토큰은 증가합니다.

홈 이동은 브라우저의 대화 ID·입력·확인 상태를 비우고 마이크와 재생을 중지합니다. 취소 후 늦게 도착한 응답을 화면이나 다음 상담에 반영하지 않습니다. 이미 서버에 도달한 요청의 저장은 완료될 수 있으며 기존 `conversation_messages` 기록 자체를 삭제하지 않습니다.

## 음성 동작

브라우저 `SpeechRecognition` / `speechSynthesis`를 사용하며 별도 `voice-ai` 서버 연결은 이번 범위에 포함하지 않습니다. 첫 마이크는 사용자가 눌러 시작합니다. 질문·선택지의 안내가 끝난 뒤 듣기를 재개하며, 화면 이동·홈·탭 숨김·모달 열기 때 인식과 재생을 중지합니다.

예: 화면의 `불빛이 어떤 색인가요?`를 음성에서는 `불빛이 빨간색인가요, 노란색인가요? 다른 색이면 그 색을 말씀해 주세요. 잘 모르시겠다면 “모르겠어요”라고 말씀해 주세요.`처럼 안내합니다. 모바일 대화에는 같은 자연어 문장을 표시해 중간 터치를 요구하지 않습니다.

원형 모션은 기존 듣기·생각·말하기 상태에 연동합니다. 추가 마이크 스트림이나 음량 분석을 요청하지 않으며 `prefers-reduced-motion`을 따릅니다.

## 소모품 게이지와 시연 데이터

10종 각각의 거리·기간 사용량을 표시하고 `max(사용 거리 / 거리 기준, 경과 일수 / 기준 일수)` 순으로 정렬합니다. 90% 이상 빨강, 70% 이상 주황, 미만 청록이며 초과 숫자는 유지하고 그래픽만 100%로 제한합니다. 기록 없음·조회 실패·불일치는 회색입니다. 같은 차량 계통을 공유하는 부품은 가장 높은 우선순위의 색을 표시합니다.

K5 2024 1.6T 엔진오일은 검토된 일반/가혹 기준만 적용합니다. **붕붕이(K5 2026 G2.0)는 2026 엔진오일 기준이 없어 `기준 확인`으로 표시**하며 2024 값을 가져오지 않습니다. 다음 9종은 `[차근 시연]` 기록이 있는 차량에만 적용되는 예시이며, 제조사 확정 교환 주기·실제 마모도·고장 판정이 아닙니다. 상세에서 시연 기준임을 표시하고 RAG에는 이 기준을 보내지 않습니다.

| 시연 항목 | 거리 | 기간 |
| --- | ---: | ---: |
| 엔진오일 필터 | 10,000 km | 12개월 |
| 엔진 에어필터 | 30,000 km | 24개월 |
| 타이어 | 40,000 km | 48개월 |
| 브레이크 패드 | 30,000 km | 36개월 |
| 브레이크액 | 40,000 km | 24개월 |
| 에어컨 필터 | 10,000 km | 6개월 |
| 와이퍼 | 15,000 km | 12개월 |
| 배터리 | 60,000 km | 36개월 |
| 냉각수 | 60,000 km | 60개월 |

로컬 시연 계정 `1`에는 붕붕이 1대(36,200 km)와 정비 기록 23건을 유지했습니다. 생성한 비교용 차량 5대와 그 기록 19건만 정리했습니다. 다른 계정과 붕붕이의 기존 기록은 건드리지 않았습니다.

[시연 JSON](../infra/db/demo-account-1.json)은 붕붕이의 합성 기록 22건을 정의합니다. 별도로 존재하던 냉각수 기록 1건은 DB에 보존하며 JSON에 넣지 않습니다. 이 파일은 실제 DB 덤프가 아니고 자동 실행되지 않습니다. `.env`, 원본 설명서·인덱스·다운로드 ZIP·실제 DB 덤프는 PR에 포함하지 않습니다.

## 검증과 남은 범위

최신 develop 기반으로 프론트 65개, API 3개, AI 33개 테스트와 Vite 프로덕션 빌드가 통과했습니다. API·AI 테스트는 서비스 컨테이너의 의존성 환경에서 현재 소스를 마운트해 실행했습니다.

브라우저에서는 PC·모바일 홈, 선택 버튼 없는 확인 질문, 입력을 보존하는 모드 전환, PC 단계별 상담의 모바일 대화 연결, 케어 상세·목록 스크롤 복원, 기록 추가 하단 패널, 원형 모션의 프레임 변화를 확인했습니다. 실제 기기 마이크·가상 키보드와 모델 답변 품질 평가는 자동 테스트 범위에 포함하지 않습니다.

차량별 공식 정비 주기 데이터, 기록 수정·삭제 및 주행거리 외 차량 정보 수정 API, 별도 음성 서버 연동은 후속 작업입니다. 실제 배포에는 인증·API 프록시와 HTTPS 구성이 필요합니다.
